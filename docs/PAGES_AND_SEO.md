## 3. Global UI Requirements (All Pages)

### Navigation
- Sticky header on scroll
- Logo: "LOOPGATE" in Space Grotesk Bold, links to /
- Nav links: Home, App, About, FAQ, Contact (no unused links)
- Dark mode toggle (top right, always visible)
- Mobile hamburger menu (transforms to X when open)
- Skip-to-content link (first focusable element, screen readers)

### Footer
- Links: Privacy, Terms, Contact, GitHub repo
- Dynamic copyright year: (c) {new Date().getFullYear()} Loopgate
- Last updated date (bottom right, small mono text)
- No "Made with AI" tag
- No social links unless real accounts exist

### Accessibility
- All images have alt text
- Hover AND focus states on all interactive elements (same visual treatment)
- Reduced-motion support: `@media (prefers-reduced-motion: reduce)` disables animations
- Minimum touch target: 44x44px
- ARIA labels on icon-only buttons

### Responsive
- No horizontal scroll at 360px viewport width
- Mobile menu tested at 360px, 375px, 414px
- 3D scenes graceful degradation to 2D diagram on very low-power devices

### Mobile Optimization
- Viewport meta tag: width=device-width, initial-scale=1
- Touch-friendly tap targets
- No fixed-width elements
